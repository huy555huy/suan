# 命理案例研究集

本目录用于把「真实案例如何被老师傅推断」沉淀成可复盘材料。目标不是堆规则，而是拆推理路径：先抓什么，如何叠证，哪里要收口，哪些信息必须追问。

## 北极星

项目目标：成为举世皆知的老师傅级命理 agent。

这句话在工程里不是营销口号，而是验收标准：

- 算盘事实必须准：干支、星曜、爻象、宅盘、时区、真太阳时、星历都不能靠猜。
- 断法必须有师承感：先定问题，再取用神/主轴，再叠岁运/四化/动爻/飞星，最后收口到可验证事件。
- 不用兜底糊弄用户：缺关键输入就追问，缺证据就保留不确定。
- 每个强断语都要能回指盘面、规则和案例范式。
- 专业度靠案例堆出来：真实案例、人工盘例、反例、错例都要进入回归集。

## 研究纪律

- 先记输入完整度，再谈结论；出生时辰、起卦时间、坐向度数、入住年缺一项，就必须标注影响。
- 事实层严格：盘面字段、干支、宫位、爻位、飞星路径必须能回到计算结果或原始案例。
- 解释层分层：机械触发可硬校验，方法规则做流程约束，经验断语只做置信加权。
- 每个案例必须写反证点，避免只找支持信号。
- 禁止把案例结论直接套到新盘；只能抽取「断法模式」和「追问清单」。
