# 断法模式库 v0

本文件从第一批案例笔记中抽取可转化为 agent 能力的模式。它不是规则库，不直接判吉凶；它定义“怎么组织证据”。

## 通用模式

### P0 输入完整度优先

- 八字：出生年月日时、性别、地点、真太阳时策略。
- 紫微：出生年月日时、性别、农历/闰月换算、排盘流派。
- 六爻：具体问题、起卦时间、起卦方式、六次铜钱/数字输入。
- 风水：坐向度数、入住/建成年、户型、门窗、水路、灶厕床、道路/动线。

Agent 行为：

- 缺硬输入时先追问。
- 输入不足但可做教学说明时，必须标注“不能下实断”。

### P1 主证据 + 辅证 + 反证

每条核心断语至少拆成：

- primary_chart_refs：当前结论最关键的盘面事实。
- supporting_refs：辅助规则/典籍/案例模式。
- counter_signals：不支持该断语的盘面因素。
- confidence：高/中/低。
- scope：断语适用范围。

### P2 老师傅式接案

Agent 不是问卷执行器。更像人的命理研判应当先“听来意、抓案眼、边盘边验”：

- 听来意：先判断用户真正关心的是事业、婚恋、六亲、迁移、健康、时机，还是初盘摸底。
- 抓案眼：先提出 2-3 个可被盘面和反馈证伪的假设，不平均解释所有字段。
- 问关键事实：只问会改变判断的问题，如出生时间来源、3 个已发生大事年份、当前问题的具体落点。
- 追问少而准：问题要能校盘、定焦点、定用神/宫位或验证应期。
- 不做冷读：不要用“你是否敏感/纠结/有贵人”这种高泛化问题作为证据。
- 人话收束：输出要讲清主轴、机会、阻力、证据和不确定处，不要只罗列盘面字段。

判断纪律：

- 用户反馈是校验材料，不是盘面事实；不能把用户说过的话包装成命理推断。
- 盘面能推出的是倾向、触发领域和时间窗口；要断具体事件，必须有岁运/宫位/用户事实共同支撑。
- 如果下一步最该补的是校盘或专项问题，直接指出，不要把用户丢给体系选择题。

## 八字模式

### BZ-P01 岁运冲日支

适用：大运或流年地支冲日支。

证据结构：

- 原局日支是什么。
- 大运/流年何支来冲。
- 被冲日支的宫位含义：配偶宫、坐支、生活节奏。
- 冲来之支十神、五行喜忌。
- 是否同时冲合月柱、年柱或时柱。

不能直接断：

- 不能只见冲就断离婚、离职、灾病。
- 没有主题问题时，只能说“关系/居处/节奏容易被触发”。

Agent 需要字段：

- `branch_triggers[].target_ten_god`
- `branch_triggers[].target_is_favorable`
- `branch_triggers[].domain_hint`

### BZ-P02 工作变动

适用：用户问事业、换工作、调动。

证据结构：

- 官杀：职位、压力、规则、上级。
- 印星：单位、文书、合同、资质、房屋。
- 驿马/迁移信号：地点变化、出差、调动。
- 月柱：事业环境与团队。
- 大运：十年职业阶段。
- 流年：触发点。

追问：

- 问的是入职、升职、换单位、调地点，还是薪资？
- 过去 3 个工作节点年份。

### BZ-P03 喜用流年

适用：流年五行落喜用方向。

证据结构：

- 用神/喜忌来源。
- 流年干支五行。
- 合冲刑害落点。
- 大运是否承接。

不能直接断：

- 喜用得力不等于全年顺。
- 若同时有冲合，必须说机会落在哪个领域。

### BZ-P04 合动

适用：流年或大运与日柱/月柱形成天干合、地支合。

证据结构：

- 合到哪一柱。
- 合的是哪一十神。
- 合来之神是否旺。
- 原局与流年谁更有力。

不能直接断：

- 合不等于吉。
- 合可能是合绊、合动、合入、合出，需结合力量。

## 紫微模式

### ZW-P01 命财官迁闭环

适用：职业主轴判断。

证据结构：

- 命宫主星：人格/承接方式。
- 官禄宫主星：职业角色。
- 财帛宫主星：回报模式。
- 迁移宫主星：外部平台。
- 四化落点：事件牵引。

不能直接断：

- 命宫强不等于事业强。
- 官禄强不等于命主舒服。

Agent 需要字段：

- `metadata.career_axis.life`
- `metadata.career_axis.career`
- `metadata.career_axis.wealth`
- `metadata.career_axis.migration`

### ZW-P02 星曜必须带宫位

适用：所有主星解释。

同一组合落不同宫位：

- 命宫：人格主轴。
- 官禄：职业角色。
- 财帛：收入模式。
- 福德：内在压力/精神享受。
- 迁移：外部环境与出路。

禁止：

- 看到 `武曲七杀` 就直接按命宫性格断，除非它确实在命宫。

### ZW-P03 四化是牵引，不是单点吉凶

适用：化禄、化权、化科、化忌。

证据结构：

- 哪颗星化。
- 落在哪个宫。
- 牵动哪条轴线。
- 大限/流年是否重复触发。

不能直接断：

- 化忌不等于一定坏。
- 化禄不等于一定发财。

## 六爻模式

### LY-P01 问题焦点决定用神

适用：所有六爻。

工作类问题拆分：

- 求职/职位/升迁：官鬼。
- 单位/合同/调令/文书：父母。
- 薪资/待遇：妻财。
- 领导/规则压力：官鬼 + 应爻。

Agent 行为：

- 问题焦点不清时追问。
- 不可只因“工作”二字自动取官鬼。

### LY-P02 卦义不能压过用神

适用：本卦为乾、泰等看似吉卦，或坎、否等看似凶卦。

证据结构：

- 用神是否上卦。
- 用神旺衰。
- 用神是否旬空、月破、日冲。
- 动爻是否生扶/克制用神。
- 世应关系。

不能直接断：

- 乾卦不一定大吉。
- 否卦不一定全凶。

### LY-P03 反向信号要看力量

适用：有忌神发动、回头克、旬空等。

证据结构：

- 忌神有无月日支持。
- 忌神是否化绝、化退、被冲。
- 用神是否持世、临月、得日。

结论方式：

- “有阻但可成”比“吉/凶”更专业。

## 风水模式

### FS-P01 坐向与替卦硬输入

适用：玄空飞星。

证据结构：

- 度数。
- 二十四山。
- 下卦/替卦区间。
- 学派。

硬要求：

- 接近边界必须复测。
- 缺度数不能排盘。

### FS-P02 动气口启动飞星

适用：住宅/商铺应事。

证据结构：

- 门、窗、路、水、人流、楼梯、收银台。
- 这些动气点落在哪一宫。
- 山星/向星/运星组合。
- 元运是否当令。

不能直接断：

- 只看宅盘不看动气口，不能断财运/健康应事。

### FS-P03 一宅多处并存

适用：宅内不同宫位吉凶混杂。

结论方式：

- 入口可吉，灶位可凶。
- 财位可旺，健康位可弱。
- 应事要落到具体人、事、空间。

### FS-P04 年月星叠盘

适用：问具体年份应事。

证据结构：

- 本宅盘。
- 年飞星。
- 月飞星。
- 动气点是否被年/月星引动。

Agent 需要字段：

- `metadata.annual_flying_stars`
- `metadata.monthly_flying_stars`
- `metadata.active_mouths`
