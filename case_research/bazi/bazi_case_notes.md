# 八字案例研究笔记

## 研究结论先记

八字案例里，师傅的真实推理通常不是“见冲就断凶”，而是：

1. 先定日主与格局承载力。
2. 再看大运给的十年环境。
3. 流年只做触发，不单独决定吉凶。
4. 刑冲合害必须落到柱位、十神、喜忌和现实问题。
5. 有事件反馈时，用反馈反校用神和应期。

## BZ-C01 林先生流年案例：喜忌、大运、流年与反馈同看

- source: https://www.igoodluck.com.tw/instance-2.htm
- source_type: public case with client feedback
- reliability: medium。网站给出师傅断语和反馈，但出生日期/完整盘面被遮蔽，不能复算。
- topic: 感情、事业、财来财去、流年应事

### 原始输入

页面记录为林先生，生于民国 71 年农历 3 月某日某时，乾造；完整生日被隐去。

### 师傅抓手

- 先看日主：庚金。
- 再定强弱与喜忌：庚金得月令生旺，喜水木，忌土，丁火不忌。
- 再看大运：21 岁前七杀运，是非、叛逆、误交损友；当前正官运相对平顺。
- 再看流年与宫位：流年犯太岁并冲月令，落到感情缘分波折。
- 最后看反馈：当事人回覆除未来子息未验，其余多处符合。

### 推理链

- 主证据：日主强弱 + 喜忌。
- 辅证：七杀运、正官运切换，说明不是单看流年。
- 应事点：冲月令不直接说“坏”，而落到当时问事中的缘分不稳。
- 反向信号：事业被断为尚称如意，说明同一流年不必所有主题都凶。

### 对 Agent 的启发

- 八字回答需要把 `day_master`、`metadata.strength`、`xi_ji`、`da_yun`、`liu_nian` 连起来。
- 如果只引用 `liu_nian.ganzhi` 就下结论，证据不足。
- Agent 应该问“当前最关心事业还是感情”，因为同一冲合落到不同现实主题会有不同翻译。

## BZ-C02 工作变动断法：印星/驿马/冲克必须先定位

- source: https://www.sohu.com/a/680607390_120295621
- source_type: method note with examples
- reliability: medium-low。不是完整命例，但断法顺序有参考价值。
- topic: 工作调动、印星、驿马、岁运触发

### 师傅抓手

- 流年或大运与原局发生刑、冲、克、害、合、值，才叫岁运感应命局。
- 工作变动常从印星、官星、驿马入手。
- 印星代表单位、手续、文书、房屋；驿马代表迁动、调动、出差、地点变化。

### 推理链

- 主证据：被岁运作用的字是否代表印星/官星/驿马。
- 辅证：该字是喜是忌。
- 方向判断：冲克忌印，可能是好岗位调整；冲克用印，可能是被动离职、手续压力或单位不稳。
- 反向信号：只有“流年见驿马”不足以断换工作，还要看是否与命局发生实际关系。

### 对 Agent 的启发

- 需要在八字盘面里补 `metadata.event_timing.*.target_ten_god` 或类似字段，显示被冲合的是印、官、财还是日支。
- 输出“工作会变动”前，必须说明是工作性质、地点、单位手续，还是上级/制度关系变动。

## BZ-C03 天地相合引发职业变化：合也会动

- source: https://www.xifengduzui.com/article363.html
- source_type: teaching case, explicitly marked virtual by author
- reliability: method-only。不能作为真实回验，但适合拆断法。
- topic: 日柱与流年天地相合、事业变化、旺衰对比

### 盘面结构

文章讨论一个教学命例：日柱与流年干支天地相合，流年财星旺，原局以印为事业结构。

### 师傅抓手

- 不是只有冲才动，合也能牵动。
- 关键问题是谁牵谁：日柱跟流年走，还是流年被命局收进来。
- 判断依据包括太岁权力、流年财星是否通根透干、日主是否足够强旺。

### 推理链

- 主证据：日柱与流年天干地支同合。
- 辅证：流年财星旺，且命主心向财星。
- 结论：可能从原来印星行业转向财星行业，如金融、商业或创业。
- 反向信号：若命主强过流年，可能是得财而非换行业。

### 对 Agent 的启发

- 现有引擎已经有部分天干合/地支合，但需要把“合住哪一柱、十神是什么、谁旺谁弱”结构化。
- 合不应默认吉；要区分合进、合出、合化、合绊。

## BZ-C04 六冲案例组：冲是事件触发，不是固定吉凶

- source: https://kandian.sina.cn/article_7879848901_1d5acf3c501901nwss.html?from=astro
- source_type: article with example cases
- reliability: medium-low。案例未给可独立验证出处，但结构完整。
- topic: 大运/流年六冲、柱位、用忌、十神定位

### 案例 A：辰戌冲财库，事业获利

- 命局：乾造甲子、丙寅、戊辰、壬戌。
- 结构：原局辰戌冲，财库被冲开。
- 岁运：庚午运加辛丑年，土势被助，丑刑戌再动辰土库。
- 应事：投资地产获利。

### 案例 B：酉冲日支卯，婚姻危机

- 命局：坤造乙亥、己卯、丁卯、癸卯。
- 流年：辛酉年冲日支卯。
- 解释：日支为夫妻宫，卯木为用被冲，七杀透干。
- 应事：婚姻危机与情绪受损。

### 师傅抓手

- 先定位冲到哪一柱：年支、月支、日支、时支。
- 再定位该支十神和宫位。
- 最后看用神/忌神与力量胜负。

### 对 Agent 的启发

- `branch_triggers` 需要携带 `target_label`、`target_ten_god`、`is_favorable_target`。
- 输出必须写“冲到了哪里”，不能只说“今年冲动大”。

## BZ-C05 命局、大运、流年的三层关系

- source: https://bazitalk.com/category/bazizhishi/9053.html
- source_type: method note
- reliability: method-only
- topic: 原局、大运、流年的层级

### 方法摘记

- 原局是先天结构。
- 大运是十年环境，能改变原局状态和喜用感受。
- 流年是触发点，权力高但不一定力量最强。
- 合、冲、刑、生克有顺序差异，不能把所有关系等价处理。

### 对 Agent 的启发

- 证据包应该要求：
  - 原局主证据至少一条。
  - 当前大运证据至少一条。
  - 流年证据至少一条。
- 若没有大运，只断流年，置信度最多中等。

## BZ-C06 本项目黄金例：1991 杭州女命事业变动

- source: `data/pro_golden_cases.json`
- source_type: internal manual reference chart
- reliability: high for engine regression, medium for interpretation
- topic: 己亥大运冲日支、2026 丙午喜用得力

### 盘面事实

- 四柱：辛未、丙申、丁巳、丁未。
- 日主：丁。
- 当前大运：己亥。
- 大运触发：亥与日支巳六冲。
- 2026 流年：丙午，喜用得力，午未六合牵动年柱与时柱。

### 推理链

- 主证据：`metadata.event_timing.current_da_yun.branch_triggers` 冲到日柱。
- 辅证：2026 `preference_label=喜用得力`。
- 收口：可以断阶段性工作节奏/关系/居处变化，但不能直接断“必离职”。

### 对 Agent 的启发

- 这条应该成为八字事业变动黄金模板：
  - 先说触发点。
  - 再说变动领域。
  - 再说喜忌方向。
  - 最后给校盘问题：过去是否在亥、巳、午、未年份有工作/居住变动。
