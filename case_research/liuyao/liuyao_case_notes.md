# 六爻案例研究笔记

## 研究结论先记

六爻的专业流程比八字更“就事论事”。老师傅不是先看卦名，而是：

1. 先定问事。
2. 定用神，且用神会因问题焦点变化。
3. 看世应与用神关系。
4. 看月日建、旬空、动爻、变爻。
5. 最后才参考卦义。

## LY-C01 工作调动但实问工资：用神从官鬼改取妻财

- source: https://www.yangyide.net/liuyao/203.html
- source_type: public case note
- reliability: medium。作者自述为旧手写案例，给出起卦时间、卦象和分析。
- topic: 工作调动、工资、取用神

### 原始输入

- 问事：去了新工作后能否提升工资。
- 起卦时间：2008-06-26 17:41，北京时间。
- 主变卦：天地否之天山遁。
- 空亡：辰、巳。

### 师傅抓手

- 虽然背景是工作，但核心问“工资能否提升”，所以取三爻妻财卯木为用神，而不是先取官鬼。
- 妻财持世且发动，有求财象。
- 但妻财化兄弟申金回头克，且逢日冲破，月令泄气。
- 原神子孙不上卦，助力不足；兄弟旺，劫财强于财。

### 推理链

- 主证据：用神取妻财，妻财持世发动。
- 反向信号：化兄弟回头克、日冲破、月令泄气。
- 结论：能有财，但不大，工资难明显上涨，辛苦得财。

### 对 Agent 的启发

- `question_yong_shen` 不能只由“工作”二字决定；应先识别焦点是职位、薪资、单位、调动还是领导关系。
- 需要在 intake 里问：“你问的是能否入职/升职，还是薪资待遇？”

## LY-C02 增删卜易谒贵：官鬼持世，回头克，应期看冲去忌神

- source: https://www.66yao.cn/?id=449
- source_type: classical case commentary
- reliability: medium。案例结构完整，属于增删卜易类卦评。
- topic: 谒贵、官鬼、回头克、应期

### 原始输入

- 酉月丙寅日，占谒贵。
- 得山风蛊之山水蒙。
- 旬空：戌亥。
- 世爻官鬼酉金发动，变子孙午火。
- 原注结果：丙子日得见。

### 师傅抓手

- 求见贵人/上司，取官鬼为用。
- 官鬼临月建且持世，说明有见面机会。
- 但动化子孙午火，子孙克官鬼，形成回头克。
- 等子日冲去午火，解除阻力，成应期。

### 推理链

- 主证据：官鬼持世且临月。
- 反向信号：化子孙回头克。
- 应期：子日冲午。
- 结论：能见，但要等阻力被冲开。

### 对 Agent 的启发

- 六爻不能只输出吉凶，要输出“成，但有阻；何时阻解”。
- 需要在盘面模型中显式暴露 `moving_lines[].change_relation`、`yong_shen.month_strength`、`response_timing_candidates`。

## LY-C03 本项目黄金例：问工作，乾卦不能直接说大吉

- source: `data/pro_golden_cases.json`
- source_type: internal manual hexagram case
- reliability: high for engine regression
- topic: 问工作、官鬼、旬空、用神偏弱

### 盘面事实

- 问事：问工作。
- 本卦：乾为天。
- 用神：官鬼。
- 官鬼位置：四爻。
- 旬空：午未。
- 用神线：旬空，强度偏弱。

### 师傅抓手

- 问工作先取官鬼。
- 乾卦有进取、主动、领导象，但不是决定性证据。
- 用神旬空且偏弱，不能按乾卦全阳直接断顺。

### 对 Agent 的启发

- 卦义最多是背景气质；用神旺衰和世应关系才是核心证据。
- 六爻解读前应先核对 `question_yong_shen` 和至少一条用神状态；用神不清时先问或标注待校，不要直接断吉凶。

## LY-C04 工作类问题的官父财三分法

- sources:
  - https://www.cnjuece.com/knowledge/20c97218-912d-4818-a460-faf3aca345dd
  - https://m.yi958.com/zb/posts/6538
- source_type: method notes
- reliability: method-only
- topic: 工作、职位、单位、收入分层

### 方法摘记

- 官鬼：职位、规则、领导、考核、工作压力。
- 父母：单位、合同、文书、手续、调动信息。
- 妻财：薪资、待遇、收入回报。
- 世爻：求测者当前状态。
- 应爻：对方、单位、外部回应。

### 对 Agent 的启发

- 对工作问题先分类：
  - 求职/升职：官鬼主。
  - 调动/合同/编制：父母主。
  - 工资待遇：妻财主。
  - 领导关系：官鬼、五爻、应爻与世爻合看。
- 问题不清时必须追问，不要默认官鬼。

## LY-C05 论坛升迁案例：忌神发动但克不动，用神持世旺相

- source: https://www.reddit.com/r/EasternOccult/comments/1pti6q5/
- source_type: public forum case
- reliability: low-medium。公开讨论，结果未必回验，但思路有参考价值。
- topic: 升迁、官鬼持世、子孙忌神

### 师傅抓手

- 升迁看官鬼为用，兼看世应与动爻。
- 若官鬼持世且旺相，是职位机会的强信号。
- 子孙为克官之神，若发动但无月日支持、化绝，则克不动用神。
- 应期取官鬼旺地或动爻相关时点。

### 对 Agent 的启发

- 反向信号不等于否定结论，要看它有没有力量。
- Evidence bundle 需要写 `counter_signals`，并给出为何未能推翻主证据。
