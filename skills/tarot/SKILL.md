# 塔罗牌解读

## Step 1: 抽牌

```
compute_chart("tarot")
```

默认凯尔特十字牌阵。拿到每个牌位的牌面（正/逆位）。

## Step 2: 读牌面

- `spread` → 牌阵名称
- `drawn_cards` → 抽到的牌列表，每张含：
  - `card_name` → 牌名（如"The Tower"/"塔"）
  - `position` → 牌位含义（如"当前处境"/"挑战"/"潜意识"）
  - `reversed` → 是否逆位
  - `keywords` → 关键词
  - `interpretation` → 基础释义

## Step 3: 解读

凯尔特十字各牌位：
1. **当前处境** — 此刻的核心能量
2. **挑战/阻碍** — 横在面前的考验
3. **意识层面** — 你知道自己在想什么
4. **潜意识层面** — 你没意识到但在影响你的
5. **近过去** — 刚发生的/正在淡去的
6. **近未来** — 即将浮现的
7. **你的态度** — 你面对此事的内在姿态
8. **环境/他人** — 外部因素
9. **希望与恐惧** — 你最期待又最害怕的
10. **最终结果** — 如果保持当前路径

解读原则：
- 逆位不是"坏"，是能量受阻/内化/过度
- 关注牌与牌之间的叙事线（而非孤立看每张）
- 大阿尔卡那（0-21）= 人生大主题
- 小阿尔卡那 = 日常层面
- 宫廷牌 = 人格面向或实际人物

## Step 4: 查引证

```
grep_classics("塔罗|大阿尔卡那|牌阵", system="tarot")
```

## Step 5: 输出

- 塔罗是**心理投射工具**，不是预测工具
- 用"牌面呈现..."/"这张牌在这个位置暗示..."的句式
- 不说"你一定会..."/"命中注定..."
- 鼓励用户将牌面解读作为自我反思的入口
- 逆位牌要解释清楚"逆位在这里可能代表..."
- 最后给出整体叙事总结："十张牌勾勒出的图景是..."
