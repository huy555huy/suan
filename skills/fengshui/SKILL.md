# 风水解读

风水不是只看一个坐向盘就断屋内吉凶。先确认用户问的是方位盘法、居家布局、办公布局、搬家择向，还是具体应事。没有户型、门窗、水路、灶厕床桌等现场事实时，只能做盘法层面的候选分析。

## 取盘

```
compute_chart("fengshui")
```

拿到坐向、运盘、飞星分布、八宅、命卦、吉凶方位等。

## 先定现场输入

- `facing_direction` → 朝向（度数 + 名称）
- `sitting_direction` → 坐向
- `period` → 当前元运（如九运 2024-2043）
- `flying_stars` → 九宫飞星（山盘/向盘/运盘）
- `ba_zhai` → 八宅（东四命/西四命，各方位吉凶）
- `ming_gua` → 命卦
- `favorable_directions` → 吉方
- `unfavorable_directions` → 凶方
- `metadata.pan_method` → 下卦/替卦
- `metadata.facing_degree_detail` → 朝向落山、离中心度数、是否替卦
- `metadata.palace_priorities` → 旺财、卧床稳定、需谨慎方位
- `metadata.site_questions` → 断门床灶前必须追问的现场事实

先看 `metadata.site_questions`。用户如果没提供现场事实，优先追问；若用户只想先看盘法，可以明确说“以下只到方位候选，不断具体布局应事”。

## 玄空飞星分析

飞星组合（山盘+向盘）的核心含义：
- 1-1: 桃花水、聪明
- 2-5 / 5-2: 大凶（病符+五黄）
- 6-8 / 8-6: 大吉（武曲+左辅）
- 1-4 / 4-1: 文昌、学业
- 2-3 / 3-2: 斗牛煞（口舌）
- 6-7 / 7-6: 交剑煞
- 8-8: 当运旺星，大利财

看用户关心的方位对应哪个宫位的飞星组合。

没有户型图时，方位候选分析可以给，具体门、床、灶布局需要追问户型。引用 `metadata.site_questions` 追问户型、测量方法、外局形势。若 `metadata.pan_method == "替卦"`，提醒用户复测罗盘度数。

## 八宅辅助

八宅把八个方位分为四吉四凶：
- 生气/天医/延年/伏位 → 吉
- 绝命/五鬼/六煞/祸害 → 凶

结合命卦看用户是东四命还是西四命，对应吉方不同。

## 问诊纪律

- 坐向度数来自罗盘或明确测量方法；接近二十四山交界时要复测。
- 断门、床、灶、书桌、收银台吉凶，需要知道它们所在宫位或户型图。
- 断财、病、口舌、学业，需要看该宫是否被门窗、水路、动线或长期使用激活。
- 化解建议务实轻量。

## 查引证

```
grep_classics("飞星|玄空|八宅", system="fengshui")
grep_rules("飞星组合|方位", system="fengshui")
```

## 盘面阅读

输出前回到 `compute_chart("fengshui")` 的 JSON：看元运、坐向、飞星、八宅、命卦和 `metadata.site_questions`。风水盘是方位材料，具体应事结合现场事实。

## 输出

- 先报基本盘面："坐 X 朝 Y，X 运盘"
- 各方位吉凶要具体到飞星组合
- 给出**可操作**的建议前，先确认现场事实；没有户型/门床灶时，只能给“候选方位”和“待现场核验项”
- 风水建议务实
- 没有户型图和门床灶位置时，给方位候选和待核验项
