# 紫微斗数解读

## Step 1: 算盘

```
compute_chart("ziwei")
```

拿到十二宫（命宫/兄弟/夫妻/子女/财帛/疾厄/迁移/交友/官禄/田宅/福德/父母）、主星分布、四化、大限、身宫等。

## Step 2: 定命宫主星

从 chart 读：
- `life_palace` → 命宫位置
- `body_palace` → 身宫位置
- `main_stars` → 各宫主星列表
- `si_hua` → 四化飞星（化禄/化权/化科/化忌）
- `five_element_bureau` → 五行局（决定起运年龄）
- `metadata.focus.life_palace` / `body_palace` → 命身宫三方四正聚合
- `metadata.focus.domains` → 事业、财帛、感情、健康等主题宫位三方四正
- `metadata.calibration_questions` → 紫微校盘追问

重点看命宫坐什么主星（紫微/天机/太阳/武曲/天同/廉贞/天府/太阴/贪狼/巨门/天相/天梁/七杀/破军/天魁/天钺等）。

## Step 3: 宫位解读

根据用户问题定位关键宫位：
- 事业 → **官禄宫**（主星 + 四化飞入情况）
- 感情 → **夫妻宫**
- 财运 → **财帛宫** + **田宅宫**
- 健康 → **疾厄宫**
- 人际 → **交友宫** + **迁移宫**
- 性格 → **命宫** + **福德宫**
- 父母/子女 → 对应六亲宫

看该宫的：
1. 主星是什么 → 基本格局
2. 有无四化飞入（化禄=机会，化权=掌控，化科=名声，化忌=阻碍）
3. 三方四正（对宫 + 两个夹宫）有无助力或冲克

优先使用 `metadata.focus.domains.<主题>`，不要只读单宫主星。事业至少看官禄宫、命宫、迁移宫、财帛宫的三方四正；感情至少看夫妻宫、福德宫、迁移宫；健康至少看疾厄宫、福德宫、命宫。

## Step 4: 看大限与流年

- `da_xian` → 当前大限走到哪个宫位
- 大限宫的主星 + 四化叠加先天盘 → 这十年的主旋律
- 流年盘叠加 → 今年具体走势

## Step 5: 查引证

```
grep_classics("紫微|命宫|官禄", system="ziwei")
grep_rules("四化|化禄|化忌", system="ziwei")
```

挑 1-2 条相关典籍/规则佐证。

## Step 6: 校验

```
verify_chart_ref(path="ziwei.life_palace", expected="...")
verify_chart_ref(path="ziwei.si_hua.化禄", expected="...")
```

## Step 7: 输出

- 先概述命盘格局（命宫主星 + 身宫 + 五行局）
- 再针对问题展开宫位分析
- 大限/流年的时间段标注清楚（"当前大限 XX-XX 岁，走 X 宫"）
- 四化影响用具体星名说明，不泛泛说"有化禄"
- 如果用户要精断，先问 `metadata.calibration_questions` 中的出生时间来源和 3 个已发生大事年份。
