# Modern Astrology·Major Aspects

> None

主要相位：合相（0°）能量融合放大、对分（180°）拉锯与平衡、三分（120°）天赋顺畅、四分（90°）紧张张力、六分（60°）机会与协作。容许度通常 6-8°。对分与四分被视为挑战相位，但同时是成长动力——意识化的紧张往往催生最深刻的转化。

**适用场景**: 解读本命盘行星之间相互作用
