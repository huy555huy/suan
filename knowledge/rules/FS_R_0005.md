# 二黑病符

**触发条件**: {"any_of": ["chart.fengshui.flying_stars contains 2"]}

**结论**: 二黑巨门临方主疾病、慢性病；忌卧室或厨房在此方位

**表现示例**: 慢性病反复, 肠胃不适, 家人健康变差

**备注**: 二黑与五黄同属土煞，二者同宫更凶；可用铜化解
