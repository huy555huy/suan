# 三张牌指向同花色

**触发条件**: {"any_of": ["chart.tarot.drawn_cards suit_count >= 3 for same suit"]}

**结论**: 三张以上同花色集中出现：权杖=行动/热情主导，圣杯=情感主导，宝剑=思维冲突主导，星币=物质主导

**表现示例**: 权杖多主冲劲十足, 圣杯多主情感纠葛, 宝剑多主焦虑争执, 星币多主务实理财

**备注**: 花色集中是牌阵的整体能量信号，优先于单张牌义解读
