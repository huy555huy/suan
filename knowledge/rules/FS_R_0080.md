# 替卦起星

**触发条件**: {"all_of": ["chart.fengshui.metadata.pan_method == '替卦'"]}

**结论**: 罗盘度数落在每山两侧替卦范围时，山向飞星须按替星诀起盘，不可沿用下卦盘

**表现示例**: 起星换盘, 吉凶方位重排, 需复测罗盘度数

**备注**: 替卦对度数敏感；接近二十四山或下卦/替卦边界时，应要求复测到 0.1 度
