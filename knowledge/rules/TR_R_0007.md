# 逆位大阿尔卡那

**触发条件**: {"any_of": ["chart.tarot.drawn_cards.*.is_major == true and reversed == true"]}

**结论**: 大阿尔卡那逆位不代表"反义"，而是该能量受阻、内化或过度

**表现示例**: 正位能量被压抑, 课题尚未学会, 能量过度失衡

**备注**: 逆位解读三原则：受阻（blocked）、内化（internalized）、过度（excessive）
