# 八白财星当令

**触发条件**: {"all_of": ["chart.fengshui.period <= 8", "chart.fengshui.flying_stars contains 8 at facing"]}

**结论**: 九运前八白为当令财星，到向主旺财；九运后退气减力

**表现示例**: 财运亨通, 投资得利, 置业有利

**备注**: 2024年起进入九运，八白退气为近旺财星；九紫成为当令财星
